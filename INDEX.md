## 🚀 Getting Started

### For New Engineers Using This Repo

1. **Read the onboarding guide**
   ```bash
   cat ~/hypershift-onboarding/onboarding-guide.md
   ```

2. **Use the MCP server**
   - Configure in Claude Code (see README.md)
   - Search docs: "Search hypershift docs for NodePool"
   - Get learning path: "Give me a beginner learning path"

3. **Request a personalized learning plan**
   - Once agents are created, invoke: `/agent learning-plan-generator`

### For Maintainers

1. **Set up daily sync**
   ```bash
   ~/hypershift-onboarding/setup-daily-sync.sh
   ```

2. **Check sync status**
   ```bash
   ~/hypershift-onboarding/scripts/sync-status.sh
   ```

3. **Review issues**
   ```bash
   cat ~/hypershift-onboarding/validation-issues.md
   ```

4. **Update docs when needed**
   - Once agent created: `/agent onboarding-updater`
   - Or manually update based on validation issues

### For Creating AI Agents (Next Week)

1. **Read the full blueprint**
